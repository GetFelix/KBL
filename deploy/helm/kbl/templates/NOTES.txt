KBL {{ .Chart.AppVersion }} is installed as {{ include "kbl.fullname" . }}.

Before the tracker serves anything, check Felix:

  work.events must be acknowledged durably. The tracker creates it as a
  durable stream with one copy, which is safe only if the brokers run with
  FELIX_ACK_ON_COMMIT=true and FELIX_DURABLE_FSYNC_MODE=on_commit. For more
  copies, create the stream yourself before the first start, with consistency
  Quorum (or on Felix's Raft engine). The tracker refuses any other setting and
  every call answers an error naming it. This chart does not install or
  configure Felix; set these in Felix's own deployment.
  See docs/work-tracker.md, "What Felix must guarantee".
