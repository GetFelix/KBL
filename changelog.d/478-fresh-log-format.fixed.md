A new work log starts at the current format, so a fresh stack's `supervise_start` launches workers with no `format_raised` by hand. A log that already has records keeps its format until a person raises it. Every refusal for the format now says which record needs which format, the log's format, and that a person raises it with `format_raised`; `supervise_status` shows it as `paused_because`, `GET /v1/me` reports each team's `log_format`, and `dev/quickstart.sh` prints it with the command to raise a log that is behind.
