Ingest writes `shipped`. When an open item's link waits on a merged root for a release, ingest records the oldest stable release after the merge whose tag contains the merge commit, which frees the link. The tracker takes it only on a root ingest imported whose reported request has a merged status, and never over a release already recorded. Each poll makes at most `release_compares_per_poll` pull request reads and compares together (default 20) and reads at most 5 pages of releases; a merge older than those pages gets no release rather than a possibly wrong one, and a tag found not to contain the merge is not compared again. A person's `shipped` replaces ingest's. Only roots something waits on cost any release requests. The ingest GitHub token needs read access to repo contents. Part of #144.
