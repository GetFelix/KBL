A review limit. `KBL_REVIEW_LIMIT` (default 3, 0 is off; the default is a guess) pauses new fix claims while In review plus fixes agents hold reaches that number. It never blocks triage, questions, reviews, resumed work or fixes a review asked for, and the dashboard header says "review full: agents paused, N/N" with the split when the review load is at the limit. `GET /v1/me` carries `review_limit` per team.
