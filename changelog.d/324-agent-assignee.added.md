An item can be assigned to an agent: `POST /v1/work/reassign` with `{"to": {"agent": "w1"}}`, or `kbl-mcp person` `reassign_item` with `to: "agent:w1"`. Only that agent can claim it; the fold refuses any other as `not_assignee`. The tracker hands the item straight to its assignee in `work_next` and never publishes it to a ready lane, so other agents never hold it, never loop on it, and spend none of Felix's handouts on it. An agent assignee that is revoked or makes no call for `KBL_ASSIGNEE_AWAY_SECS` (600 by default) is dropped by the tracker, and the item goes to the team. This is format 13 (no new record): raise each team's log to 13 after every tracker and dashboard page is this build or newer (docs/upgrades.md). The assign picker on the dashboard does not list agents yet.

The new `format_13` golden folds a log that assigns an item to an agent, refuses another agent's claim, and lets the assignee claim it.
