An item can need something only some agents have (`needs`, such as `azure`, `gpu` or `network`), set by triage (`work_triage`), a person (`classify_item`) or an intake rule (`label_needs`) from the team's vocabulary. An agent passes `capabilities` on `work_next` and `work_peek` and is handed only work whose needs it covers; skipped work spends no ready record, also across a restart. `lift_resource` (`POST /v1/work/lift-resource`) ends every block on one named resource in one record. This is format 20 (docs/upgrades.md). The new golden is `format_20` (`wasm/golden/format_20.jsonl` and `format_20.state.json`, from `core/tests/work_format_20.jsonl`), and folds that include a snapshot are dropped once because the fold revision moved.
