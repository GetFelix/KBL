A work loop for MCP hosts. The `work_next` reply carries a `loop` line (and one when nothing is ready) telling the host to keep taking items, and the README has the prompt. `dev/agents.mjs` starts N host sessions, each with its own `.mcp.json` and tokens, restarts one that exits early, and stops them all on Ctrl-C. `dev/check-agents.mjs` runs it against the dev stack with a scripted host.
