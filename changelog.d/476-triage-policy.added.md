A triage policy accepts routine triage without a person. Set `KBL_TRIAGE_POLICY_FILE` to a JSON file of rules over what triage recorded (`tiers`, `areas`, `deny_areas`, `types`, `sizes`, `deny_needs`); when a finished, plain triage matches a rule the tracker writes `accepted` as itself with the rule's name in `admitted_by`, and everything else stays in Needs you. A person can take a policy acceptance back from the dashboard (`undo_admission`, `POST /v1/work/proposals/undo-admission`), which returns the root to Triage and keeps the policy off it. The dashboard shows "Admitted by policy <rule>" on the item and in its history. This is log format 25, so raise the format before the policy runs; with no policy file a person accepts each triage.
