The tracker, `kbl-ingest` and `kbl-mcp` export OpenTelemetry traces over OTLP/HTTP, off until `OTEL_EXPORTER_OTLP_ENDPOINT` (or the traces-specific variable) is set and configured by the standard `OTEL_*` variables. Spans cover tracker requests (named by route template), claims, fold applies and rebuilds, ingest polls and write-back, MCP tool calls and their calls to the tracker, and a W3C `traceparent` joins each caller to the tracker request. Attributes hold templates, tool names, source kinds and result words, never ids, text or tokens. A new `kbl-trace` crate holds the setup. See docs/observability.md. This completes [#127](https://github.com/GetFelix/KBL/issues/127).
