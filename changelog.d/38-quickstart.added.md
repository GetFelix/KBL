A quick start: `dev/quickstart.sh` runs Felix, felix-gateway, the tracker and the dashboard locally in containers built from the checkout (Docker or Podman), all on 127.0.0.1, and `node dev/connect.mjs` writes an `.mcp.json` that points Claude Code at `kbl-mcp` with absolute paths and mode 600. It is a single-user stack with a stand-in identity provider, not a deployment. CI runs it on a clean runner.
