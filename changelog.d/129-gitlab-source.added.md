Ingest has a GitLab source. A `gitlab` worker reads the issues of a configured set of projects on GitLab.com or a self-managed instance, picked by label, milestone, assignee or type, maps priority labels to tiers, turns "is blocked by" links into edges, and reads the merge request an agent reports with the same checks as a GitHub pull request: our own login opened it, it came after the first claim, it is tied to the item by branch or a closing reference, and it merged into the default branch by someone other than us. It signs in with a group or project access token (`read_api`, and `api` only where a rule writes back), refuses plain http except on loopback, and writes back a comment and a close or reopen only where a rule asks. `gitlab` is a known source for `ingest_sources` in the token file.
