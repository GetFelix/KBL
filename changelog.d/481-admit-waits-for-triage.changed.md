Admitted roots now wait for their triage to be accepted, by a person or by a triage policy, before any agent is handed their fix. Admit mode no longer writes `accepted` for a rule that runs triage, so `work_next` and `work_peek` show triage and augment first. This applies at every log format, so it is a behaviour change on upgrade: to keep the old auto-accept for issues that are already well specified, set `"triage": "skip"` on the rule. The intake rule's tier is kept as the last choice: an accept takes a person's tier, then triage's, then the rule's (`intake_tier`, format 25).
