Ingest takes its request budget from the pool. A worker that serves a connection spends its share of the budget pool set with `PUT /v1/org/budgets/{pool}`, in proportion to the sources it holds leases on, and uses the pool's kept-back and wake numbers. Webhook wakes spend a wake share inside the kept-back part and wait for the interval when it is spent. A rate limit answer is shared through `PUT /v1/ingest/backoff/{pool}` (the later time wins, capped at an hour), so one worker's refusal stops every worker in the pool. Behaviour change for existing files: `poll_seconds` below 60 now polls every 60 seconds. `budget_share` still defaults to 0.5, because GitHub counts its limit per account; a bot account or GitHub App can raise it to 0.9.
