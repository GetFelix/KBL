A tracker restart keeps a direct claim (one handed straight to an item's agent assignee) even when the item was reassigned while the agent held it. Before, the restart polled the ready lanes for it, which spent a Felix handout on other items' head records, and then released it as lapsed before the deadline the agent was given, so a new assignee could start a second attempt while the old holder still worked. The tracker now records whether each claim was direct, keeps such a hold for one visibility period from the restart, and polls nothing for it. Snapshots from earlier builds are not read; the tracker folds the log instead.

The dashboard's assign picker lists the team's agents beside people, from the new person route `GET /v1/work/agents` (agents not revoked), and assigns with `{"agent": name}`.
