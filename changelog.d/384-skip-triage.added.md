An ingest rule can set `"triage": "skip"` (with `admit`) to import issues that are already well specified straight to Ready to fix, with no triage or augment item. `kbl-ingest check` reports it ("admits straight to ready"), and the dashboard shows "triage skipped by rule <name>". The choice is recorded as an optional `triage_skipped` field on the tracker's `accepted` record; it changes no stage, so the log format is unchanged, and only the tracker may write it.
