Supervise tools in `kbl-mcp`: with `KBL_SUPERVISE_CONFIG`, an agent runs a pool of worker agents of any vendor with `supervise_start`, `supervise_stop` and `supervise_status`. Workers start from launch profiles (`kind = "command"`, an argv template run without a shell, with a per-worker MCP config in JSON or TOML written mode 600; or `kind = "hook"`, which hands a hosted agent a one-time code it trades at `POST /v1/work/workers/exchange`). A fit table picks each worker's profile and model from the item's tier, kind, type, area, size and needs, and a timer tops the pool up while ready work matches, pausing after repeated failures. A worker's `kbl-mcp` holds it to the pool's filter (`KBL_WORK_FILTER`). Example profiles for Claude Code, Codex CLI and GitHub Copilot CLI are in `docs/supervise-profiles.md`; `dev/fake-worker.mjs` is the scripted worker CI runs.
