The dashboard's Metrics dialog shows time in each stage (p50 and p85), items done per day and week, rework (redos, reopened, failed attempts per done item), cost per done item (per model where recorded), and supervision (items a person touched, records a person wrote, time waiting on a person) for the last 7, 30 or 90 days. The fold computes them from accepted records in `metrics_json`, so a refused record never counts and an item reopened and done again counts once. No record or format change and no golden file changes: the golden stems are untouched. See docs/flow-metrics.md.
