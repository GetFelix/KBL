`kbl-ingest check --config ingest.json` validates a config with the worker's own parser, tests each credential, reports the permissions every rule needs, and dry-runs the first poll to list what each rule would import (first matching rule wins, caps applied). It only reads: the vendor connection refuses any request but a GET. `--json` prints the report, and the exit status is 1 when anything is an error. `kbl-tool source init github|jira` writes a starter config. [docs/ingest-setup.md](docs/ingest-setup.md) is the operator guide.
