The dashboard's Spend dialog lists models waiting for a price in a card, where a
signed-in person can set one (it is not a Needs-you item and blocks nothing), and
shows "check pricing" next to a model whose oldest price is more than 90 days old
(`?price_age_days=N` changes the age). The spend view gains `prices`: the latest
price of each model and unit and when it started.
