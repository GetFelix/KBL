`kbl-mcp person` serves a person's card actions and My queue as MCP tools: `my_queue`, `accept_proposal`, `reject_proposal`, `answer_question`, `set_tier`, `flag_item`, `unflag_item`, `add_note`, `retry_item`, `snooze_item`, `park_item`, `unpark_item` and `unblock_item`. It runs as a separate process with a person's token in `KBL_PERSON_TOKEN` and refuses to start with an agent's token, so an agent never gets these tools. The tracker still checks every route and records the person.
