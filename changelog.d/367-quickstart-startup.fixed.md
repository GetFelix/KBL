The quick start no longer prints the dashboard link before the tracker serves. The tracker retries its Felix setup calls while a fresh broker settles instead of exiting, `dev/up.sh` waits for the tracker and the dashboard's proxy and prints the tracker log on a timeout, and the dashboard's nginx looks the tracker up again by name, behind a tracker healthcheck. With `KBL_IMAGE_TAG` set, the quick start refuses a checkout of another version and never builds.
