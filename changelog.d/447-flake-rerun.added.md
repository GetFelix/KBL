Known flaky checks are re-run once (format 22). A person keeps a flake list (`GET`/`POST /v1/work/flakes`, `POST /v1/work/flakes/clear`); when a red check matches an entry, ingest re-runs the failed jobs through GitHub and records the check as pending, so a flake that passes on re-run never becomes work. `flake_retried` is kept on the item and each entry counts its hits. The GitHub credential needs Actions write (the `actions: write` App permission) for the re-run; without it the check goes the normal way. New golden logs: `core/tests/work_format_22.jsonl` and `wasm/golden/format_22`.
