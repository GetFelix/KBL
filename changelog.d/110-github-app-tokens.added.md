Ingest can sign in as a GitHub App. `github.app` takes the App id, an installation (by id, repo or organization) and the private key file. Ingest signs the JWT, mints installation tokens, keeps each until five minutes before it expires, and mints again once if GitHub answers 401. `token_file` still works and wins when both are set; `token_env` comes last. The key file must be mode 600 or 400. A reinstalled App is found again after a 404 or 401 on the old installation id. Ingest warns when the API base is not https or when several credentials are set.
