A design for a dashboard Sources view: connect GitHub, Azure DevOps, Jira and GitLab sources with admin-consented credentials, prove a person may connect them, and pick up changes without restarting ingest. It also designs ingest for one org-wide installation serving many teams: a shared request budget with adaptive polling, a tracker-side webhook router, per-source state with leases so several workers split a connection, and worker keys that can be added without pasting secrets again (`docs/design/sources.md`).
