A design for a dashboard Sources view: connect GitHub, Azure DevOps, Jira and GitLab sources with admin-consented credentials, prove a person may connect them, and pick up changes without restarting ingest. It also designs ingest for one org-wide installation serving many teams: a shared request budget with adaptive polling, a tracker-side webhook router whose deliveries are bound to one connection and deduplicated, per-source state with leases so several workers split a connection and stop upstream calls before a lease can move, and worker keys pinned on each worker that can be added without pasting secrets again (`docs/design/sources.md`).
