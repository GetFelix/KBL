Ingest has an Azure DevOps source. An `ado` worker reads the work items of an organization's projects, picked by tag or by a saved query, maps Priority 1 to 4 to tiers, turns predecessor and child links into edges, and maps an area path to the repository agents work in; an item in an unmapped area waits in Needs you. It signs in with a personal access token or a Microsoft Entra service principal, and writes back a comment, a pull request hyperlink and a state change only where a rule asks. `ado` is a known source for `ingest_sources` in the token file.
