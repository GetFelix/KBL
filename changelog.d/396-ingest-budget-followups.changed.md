Ingest counts the requests that fetch a token. A GitHub App's installation-token mint and installation lookup, and an Azure DevOps Entra sign-in, are charged to the request budget and wait when the vendor has asked for a pause. A config that still sets `reconcile_every` is now refused at start with an error that names `reconcile_hours` and a value worked out from `poll_seconds`; the old key is not accepted, because the poll gap now stretches with the budget and no fixed number of hours matches it. `docs/ingest-setup.md` has a budget table per vendor: Jira and Azure DevOps report no hourly limit, so the budget assumes 5,000 an hour unless `budget_per_hour` is set.
