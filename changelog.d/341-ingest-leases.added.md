Ingest source leases: `PUT /v1/ingest/leases` renews a worker's leases and takes the sources rendezvous hashing gives it once they are released or 30 s past their 90 s expiry, raising the epoch on each take. Group membership is kept in the cache, so every tracker assigns the same way. A worker with `tracker.group` set holds the config long poll on its own task, renews every 30 s, polls only the sources it holds, and makes no upstream request once its last successful renew is 60 s old by its monotonic or wall clock, cancelling any request still running. A stopping worker stops its heartbeat before it releases its leases. The config answer lists the worker's assigned sources and leases when it names its `instance`. A leased worker never polls a configured repo its connection does not name, and warns about it. Comment write-backs carry a hidden mark so a retry after a cancelled request does not post twice. A worker run that left is not let back in by a late renew.
