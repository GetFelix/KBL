Time to first human action is measured: the fold records when an item starts waiting on a person (a proposal, a question, a failure, a PR in review) and which person record ends it, from existing records only, and `GET /v1/work/metrics/time-to-human?days=` returns the team's count, p50 and p90, per reason, with the open waits reported apart. A state restored from a snapshot has not seen the waits before it, so `truncated` is true for windows reaching back before its first later record. The dashboard has no Metrics tab yet, so this is REST only.
