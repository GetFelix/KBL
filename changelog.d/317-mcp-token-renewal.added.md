`kbl-mcp` renews its Felix token from an ID token, so a 15 minute token no longer ends an agent's session. Set `KBL_FELIX_ID_TOKEN_FILE` (mode 600) or `KBL_FELIX_ID_TOKEN_COMMAND` with `KBL_FELIX_CONTROL_PLANE` instead of `KBL_FELIX_TOKEN`. It renews on a timer and reconnects to Felix after each renewal, so forwarded writes carry a live token. A held claim keeps standing across a renewal, and a failed renewal keeps the current token until it expires. `KBL_FELIX_TOKEN` still works as a fixed token. The quick start's `dev/connect.mjs` now writes the agent's ID token to `dev/state/<agent>.id-token` and a config that renews from it; `--fixed-token` writes a fixed Felix token as before.
