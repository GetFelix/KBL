A non-terminal write by an agent or a person (a note, a post, an ask, an edit, a link, a decision and the rest) takes an optional `request_key`. A retry with the same key and body writes nothing and answers with the first write, `replayed: true`, including after the tracker restarts. The same key with another body is `409` `request_key_reused`. Each caller's last 256 keys are remembered. The key is a new optional `req` field on the record, which readers without it ignore. The `kbl-mcp` write tools take `request_key`.
