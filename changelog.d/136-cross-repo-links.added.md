A link holds an item back across repos and sources. The core fold names each blocker (`State::blockers`), and the dashboard's Blocked view lists only items in the Blocked stage, not triage or held ones. Each blocker shows its repo when it is a different one, else its source (such as `jira`), and "release" when it is merged and the link waits for the release. Only GitHub items name a repo for display (`State::repo_of`); an Azure DevOps `org/project` still drives rules and spend but is not shown as a repo.
