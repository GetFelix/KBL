The GitHub worker now records the state of an agent's pull request on a Jira root, so a Jira rule's `transition_on_merge` fires when the request merges. Token files can tie an ingest worker to one source with `ingest_sources`; a tied worker reaches only that source's roots, except that the `github` worker may write `pr_status` on any root. The startup warning about `transition_on_merge` is gone. A tied worker other than `github` lists only its own source's roots, and the tracker refuses a token file that ties some workers and not others, names an unknown source, or has a key it does not know. An older tracker ignores `ingest_sources`, so downgrading removes the ties.
