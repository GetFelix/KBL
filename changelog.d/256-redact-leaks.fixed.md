Redaction now cuts private keys whose header and `END` line are URL-encoded (`-----BEGIN%20PRIVATE%20KEY-----`, `-----BEGIN+PRIVATE+KEY-----`), key bodies that escape `/` as `\/` the way JSON can, and PGP keys with more than 16 armor lines before the body. An armor line that names another key header now ends the armor, and that header is read as its own key. Records already on the log are unchanged.
