Ingest can read a Jira site: a rule's JQL filter selects issues, priority maps to tiers, `Blocks` links and sub-tasks become edges, and an issue whose component maps to no repository waits in Needs you. Write-back adds a remote link and a comment for an agent's pull request and applies a configured workflow transition. Sign in with an API token or an OAuth access token held by ingest only. A worker serves one source, so `github` and `jira` are exclusive in its config.
