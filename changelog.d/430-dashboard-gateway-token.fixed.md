The dashboard no longer sends a signed-in tab's token to another server: a `?gateway=` link without a token keeps the saved gateway, gateway addresses must be `wss://` (or `ws://` on localhost), and the gateway host shows beside the connection status. The dashboard image downloads a pinned, checksum-verified rustup-init and runs `npm ci --ignore-scripts`, CI actions are pinned to commit SHAs, and the chart sets ephemeral-storage requests and limits.
