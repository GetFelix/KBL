The dashboard has a board (`V` switches list and board; `H`/`J`/`K`/`L` move), filters by source, tier and repo from what the log recorded, views in the address (`view=blocked`, `layout=board`, filters and search) that can be saved by name to the sidebar, with the Blocked view composing with all of them and board cards saying what a blocked item waits on, a compact density, and a Menu button on small screens. The WebAssembly fold's item list now carries each item's recorded tier, source and repo. An older `?view=board` link or saved view still opens the board and is rewritten to `?layout=board`. Filter selects with no value now show Any instead of a blank.
