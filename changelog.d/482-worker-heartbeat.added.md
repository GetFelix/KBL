The supervisor records once a minute which command workers' processes are still running (`worker_alive`, format 26, `POST /v1/work/workers/alive`). The dashboard shows `process running` or `no heartbeat for 7 min` in the Workers dialog and next to a holder on cards, rows and the Now line, so a worker in a long quiet step is told from a stuck one. Raise the log to format 26 for the heartbeat to be written.
